From the previous universalreading instance on which you were before, go to
All articles, then export these articles as json.

![Export depuis universalreading v2](../../../img/user/export_v2.png)

From your new universalreading instance, create your user account and click on
the link in the menu to proceed to import. Choose import from universalreading
v2 and select your json file to upload it.

If you encounter issues during the export or the import, don't hesitate
to [ask for support](https://gitter.im/universalreading/universalreading).
